# Changelog

## 0.3.0 — 2026-10-10 — first public alpha

- Publish all original wrapper code under Zero-Clause BSD (0BSD).
- Expose 40 CLI/MCP operations across C++, maps, assets, runtime and workflows.
- Add structured brushes, entity removal and optional editor launch adapters.
- Add fail-fast build/model/map/test/package jobs with child cancellation.
- Support native compilers, QC models, VTF/VMT assets, PCM audio and VPKs.
- Verify an HL2MP game and custom map on a loopback dedicated server.
- Fix installer dependencies and add portable tool/runtime configuration.
- Add 53 tests, including hermetic MCP and pipeline failure/cancellation checks.
- Exclude local state and third-party binaries from Git and source releases.

Versions 0.1 and 0.2 were local prototypes, not prior public releases.
